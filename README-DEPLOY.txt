CALCNEXUS VERCEL READY

1. Upload the contents of this folder to the existing Vercel project, replacing the old index file.
2. Make sure the project root contains:
   index.html
   vercel.json
   robots.txt
   sitemap.xml
   privacy.html
   terms.html
3. Deploy.
4. Test:
   https://calchub.cyou/
   https://calchub.cyou/privacy
   https://calchub.cyou/terms
   https://calchub.cyou/p/discount-calculator-en.html
5. In Google Search Console, submit https://calchub.cyou/sitemap.xml after deployment.
